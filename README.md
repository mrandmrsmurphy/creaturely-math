# Creaturely Math

*Mathematics as a finite creature does it, before an infinite God.*

An [Obsidian](https://obsidian.md) vault of mathematics that is finite, creaturely and certificate-explicit: a realist about what numbers are, a constructivist about how we know them, an ultrafinitist about how big mathematics is. Every "=" carries a stated warrant.

## Reading it

Start with [`Meta/What this project is.md`](Meta/What%20this%20project%20is.md) — the whole position in one reading, including what is not being claimed. Then `Home.md` (the map) and `Meta/Future Directions.md` (the to-do list, including what is settled and what is open). To browse as intended, open the folder as a vault in Obsidian; the notes also read as plain Markdown on GitHub.

## Layout

`Foundations`, `Number`, `Geometry`, `Trigonometry`, `Change`, `Logic`, `Symmetry`, `Measurement`, `History`, `Pedagogy`: the mathematics. `Meta`: guidelines and the open-work Agenda. `Log`: the change log. `AIOS`: working memory for AI-assisted sessions (not mathematics). `images`: figures.
