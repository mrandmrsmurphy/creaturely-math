# Creaturely Math

*Mathematics as a finite creature does it, before an infinite God.*

An [Obsidian](https://obsidian.md) vault of mathematics that is finite, creaturely and certificate-explicit: a realist about what numbers are, a constructivist about how we know them, an ultrafinitist about how big mathematics is. Every "=" carries a stated warrant.

## Reading it

Start with `Home.md`, then `Meta/Future Directions.md`. To browse as intended, open the folder as a vault in Obsidian; the notes also read as plain Markdown on GitHub.

## Layout

`Foundations`, `Number`, `Geometry`, `Trigonometry`, `Change`, `Logic`, `Symmetry`, `Measurement`, `History`, `Pedagogy`: the mathematics. `Meta`: guidelines and the open-work Agenda. `Sources`: snapshots of source texts. `Log`: the change log. `AIOS`: working memory for AI-assisted sessions (not mathematics). `images`: figures.
