# Structure, Change, and Tools — three more ladders

The raw document gives each of these a bare numbered list. They parallel the [[Number Hierarchy]] and [[Geometry Hierarchy]]: **ordered by how much you must assume.** Murphy's "home" level in each is **not stated** — filling that in is the main task here ([[Future Directions]] item 7).

## Algebra

1. Magma — set + binary operation, no rules
2. Semi-group — associativity
3. Monoid — identity
4. Group (4a. Abelian)
5. Ring (5a. Commutative)
6. Integral Domain (6a. UFD, 6b. PID)
7. Field

**Category theory = this plus Tools** ("the relationships between structures"). Note the *Constructible Trig* book already lives at the top: 𝕂 is a field; ℙ¹(𝕂) with ⊕ is a group; the "Discrete Group… exact but not divisible" (ch. 5/12 outline). Precalculus for Everyone starts at the bottom (Cayley tables, groups, then abstract algebra).

## Change (calculus and its foundations)

1. **Discrete** — differences, sums, no limits ([[Discrete Calculus]])
2. **Non-Standard Analysis (ε)** — glossed "the right foundation for calculus", i.e. [[Infinitesimals]]
3. **Non-Standard Complex Analysis** (removing poles)
4. **Combinatorial Analysis**
5. **ε–δ Analysis** — "technically correct but pedagogically dishonest — hides the infinitesimal intuition that drives the reasoning"
6. **Measure Theory**
7. **Dirac delta** — "a function that is not really a function"
8. **Naked Infinities**

## Tools (logic and foundations)

5. First-order

8. Modal

10. **ZFC**

## Observations (AI, for Murphy to confirm)

- The ladders put the **suspect machinery at the top** (naked infinities; ZFC; large cardinals; level 12–14 numbers): the same pattern as the number hierarchy. A uniform principle would say: *each rung is admissible if you can state its certificate*.
- **Logic:** proof by contradiction is permitted to prove a **negative** and never to conclude an existence ([[Certificates]]), which is compatible with `me.md`'s "strict algorithmic constructivist." Which rung is "home," and where **excluded middle** holds, is not yet stated: it is unavailable for statements about infinitesimals ([[Infinitesimals]]). See [[Future Directions]] item 7.
- **Change:** level 2 (NSA, ε): the infinitesimals are reciprocals of numbers past the threshold, with no excluded middle among them; see [[Infinitesimals]].
- Rung 8 of Change and rung 11 of Tools are where the **Babel** language lands: [[Five Acts]].
